# 双链系统

知识卡片的双链插入规范。

---

## 🔗 对话双链

**本质**：标记用户在哪里"停下来"产生疑问的历史记录

**操作**：用户看文档 → 产生疑问 → 对话形成新卡片 → 把新卡片标题作为双链插入源文档

**格式**：`[[项目/[项目名]/知识卡片/[序号]. [标题]|[序号]. [标题]]]`

**无需前缀**：
- 直接以 `项目/` 开头即可
- Obsidian 会自动从 Vault 根目录解析

**示例**：
- 双链：`[[项目/AI为什么能秒懂/知识卡片/01. xxx|01. xxx]]`

---

## 📋 双链插入流程（6步）

### 步骤1：判断来源

AI根据对话内容自主判断（不询问用户），优先级：
- 问题直接提及某文档/卡片 → 那个文档
- 问题延续上一轮话题 → 上一轮对应源
- 问题涉及初始文档概念 → 初始文档
- 无法判断 → 初始文档末尾

### 步骤2：Read源文档

### 步骤3：匹配插入位置

理解对话逻辑，判断用户在哪里"停下来"产生疑问：
- 首次提问 → 插在对应内容位置
- 整体感受（"看完后"、"整体来说"）→ 插在末尾
- 综合疑问（涉及多处）→ 插在最核心位置

### 步骤4：插入双链

格式：在匹配位置后换行，单独一行，前后不空行，使用别名语法`[[完整路径|序号. 标题]]`

### 步骤5：Edit保存

### 步骤6：处理多张卡片

逐张处理：生成卡片1 → 判断来源 → Read → 匹配 → 插入 → 保存 → 生成卡片2 → 读取最新源文档 → 匹配 → 插入 → 保存
